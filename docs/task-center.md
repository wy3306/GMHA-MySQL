# 任务中心口径

任务中心只回答一个问题：用户发起的业务操作现在执行到哪里。它不是平台资源变更审计，也不是采集任务、心跳和回调日志的汇总页。

## 展示范围

以下用户操作必须在任务中心形成一条业务任务：

| 业务域 | 任务 |
| --- | --- |
| MySQL 实例 | 安装、卸载、启停、参数修改、账号与权限、索引、在线 DDL、归档、升级与升级预检 |
| 集群 | 批量安装/卸载、拓扑初始化、架构调整、MGR 与 Router 操作、滚动升级、VIP 与故障切换、整集群清理 |
| 备份恢复 | 立即备份、集群备份、恢复、按时间点恢复、闪回 |
| Agent 与 Manager | 安装、升级、卸载、手动恢复、节点操作、VIP 切换、Manager 升级 |
| 诊断与自动化 | SQL 会话终止、数据库巡检、火焰图、用户提交的集群自动化、AI 运维工作流 |
| 软件包执行 | 下载、校验、删除以及影响运行环境的软件包操作 |

操作创建了原生业务任务时，任务中心直接复用它，不再额外创建“平台操作”外壳。只有同步接口本身没有任务模型，或一次操作产生多个尚未归组的执行任务时，才创建一个平台业务父任务。

## 不展示范围

以下内容仍可在各自资源页、审计数据或内部执行记录中查询，但不进入任务中心：

- 机器、集群成员、SSH 凭证等资源资料的新增、修改、分配和预检；
- 机器静态信息、动态指标、MGR 状态等页面刷新或平台自动采集；
- Agent 注册、心跳、版本探测以及各类 Agent/任务结果回调；
- 动态采集、告警、备份策略、账号预设、火焰图计划、软件包存储等配置维护；
- AI 会话与消息本身；AI 实际执行的运维动作仍进入任务中心；
- 平台自动恢复等后台自治记录；用户手动触发的恢复操作除外。

内部采集和探测任务仍需持久化，供 Agent 派发、结果回报及故障排查使用，但其可见性为 `internal`。

## 任务关系

任务中心采用“业务父任务 → 执行节点 → 步骤 → 事件”的单一关系：

1. 一次用户提交只能有一个顶层业务任务。
2. 批量、多机和多阶段操作都挂到同一个父任务，不在列表中拆成多行。
3. 列表状态和进度由全部执行节点聚合；任一执行节点失败，父任务最终为失败。
4. 执行节点只在任务详情的执行流程中出现，用于查看单机步骤和日志。
5. 删除业务任务时连同全部执行节点、步骤和事件一起删除；只有已结束或已跳过的任务可以删除。
6. Manager 自己驱动的架构调整、集群初始化、滚动升级和 AI 工作流，以自身状态机为准，执行节点不能提前完成父任务。

## 跳过与恢复

任务中心不根据按钮名称猜测是否能撤销操作。详情接口返回服务端计算的
`controls`，页面必须展示其允许状态和原因：

- 只有尚未下发、没有子任务且不属于父级编排的任务可以跳过；跳过状态为
  `skipped`，所有未开始步骤同步标为跳过，并清除持久化命令正文。
- 已下发或运行中的任务不能标记为跳过。当前 Agent 协议没有进程级取消与确认
  回执，直接改 Manager 状态会造成“页面结束、远端仍执行”的错误状态。
- 采集、检查和火焰图任务属于 `not_required`，不修改目标资源，无需回滚。
- MySQL 卸载属于 `irreversible`；恢复依赖重新安装和已验证备份，不能显示一键回滚。
- 安装、拓扑、架构和集群级任务属于 `manual`，按日志及恢复计划处理。
- 失败的 MySQL 安装任务在兼容 Agent 在线时可选择“修复后继续”。Manager 保留
  已成功步骤，只把失败步骤及其后续步骤恢复为等待状态；Agent 从第一个未成功
  步骤继续。旧 Agent 不具备步骤状态协议，升级并重新连接前不会开放该操作。
- 初始化步骤续跑前会检查数据目录：完整初始化可直接继续，空目录可重新初始化；
  半初始化目录会再次拒绝执行，必须先人工核验并清理，避免覆盖现有数据。
- 声明了受保护恢复命令的任务属于 `automatic`。Agent 首次失败时自动恢复；只有
  收到结构化的自动恢复失败结果后，任务中心才允许创建独立的恢复重试任务。

跳过确认文本为 `SKIP <task-id>`，修复后继续为 `RETRY <task-id>`，恢复重试为
`ROLLBACK <task-id>`。
恢复重试不会覆盖原失败任务，原任务、自动恢复结果和新恢复任务均保留审计记录。

## 新增操作检查清单

新增可执行 API 时必须确认：

- 用户发起的执行是否创建或返回一个业务任务；
- 多目标任务是否在开始执行前创建父任务并传递 `ParentTaskID`；
- 内部探测是否标记为 `internal`，或作为业务父任务的执行节点；
- 接口返回的 `task_id`、`run_id` 或 `parent_task_id` 是否指向已有业务任务；
- 任务类型是否已在任务中心提供名称、状态、进度和安全脱敏后的展示信息。
